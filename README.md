# Apologetic Toaster

A one-sentence pitch for a ridiculous invention that fixes a tiny everyday annoyance: burnt toast.

> "A toaster that apologizes out loud every time it burns your bread, then writes a formal letter of complaint to itself and files it in a drawer you will never open."

## The joke

Burnt toast is a tiny, universal annoyance. This toaster "fixes" it the most
bureaucratic way possible: it apologizes out loud, then writes a formal
letter of complaint to itself and files it in a drawer you will never
open. The appliance takes full responsibility and does absolutely nothing
about it — the twist lands in the last few words.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`), validates the competition gate (1–220 characters, a single
line, exactly one sentence, no trailing newline), and reads the file back
to confirm the bytes on disk match the entry exactly.
